## Reproduce safely

Follow [setup](setup.md), including examples/ignored local configuration and the explicit seed. Use a separate test database ending `_test`. Database fault tests create and remove temporary notification triggers and must never run against real customer records. Start API/web first; run login-heavy suites serially and allow at least a minute between suites. Root tests never automatically erase the database.

```sh
npm run contracts
npm run typecheck
npm run lint
npm run build
npm --prefix aqours-api test
npm --prefix aqours-web test
npm --prefix aqours-app test
npm run test:api
npm run test:browser
npm run test:maintenance
npm run test:operations
npm run test:recovery
npm run test:map
npm run test:seed
npm run check:repository
```

The browser runner uses `/usr/bin/chromium`, creates its `.cache/tmp` and `.local/browser-profile` directories, and keeps generated output in this repository. If Chromium is unavailable, install it through your normal approved environment setup or change the runner's executable path to a compatible local installation; an unavailable browser is not a passing check. Native commands/toolchain selection and generated-directory policy are in the Android guide.
