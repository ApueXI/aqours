## Supplier mutation dialogs — 23 October 2026

Supplier create, edit and record-transition forms use a shared accessible modal: accounts, connections, zones, guidance/rule versions, incidents/publications, advisories, report review/association/internal notes, assistance transitions/collection, pickup sites/sessions, monitoring configuration and temperature bands. Existing permission checks, payloads, expected versions, previews and uncertain-action retry identities remain with their forms. Successful saves close the dialog and report that records are refreshing; validation or server errors retain the dialog and entered values. Escape and Close request confirmation when the form is dirty; pending or uncertain actions block dismissal. Backdrop clicks do not dismiss. The dialog has a scrollable body and fits narrow viewports.

Conversation composition, login, filters/search, reservation lookup, forecast refresh and notification read actions remain inline because they are not create/edit record forms. The Distribution `create=1` link still opens session creation and is cleared when that dialog closes. Executed modal evidence and its mock-only boundary are recorded in [verification](verification.md#supplier-mutation-dialogs--23-october-2026).
